# Return Policy

Voltix accepts returns of most items within **30 calendar days of delivery**. Voltix Care+ members get an extended **45-day** return window on devices covered by their plan.

## Eligibility

To be eligible for a return, an item must:

- be returned with all original accessories, cables and manuals;
- have no physical damage caused after delivery;
- not be on the list of non-returnable items (see "Non-Returnable Items").

Opened items can be returned. Opened laptops, tablets, monitors and drones are subject to a **15% restocking fee** unless the item is defective or Voltix shipped the wrong item.

## How to start a return

1. Sign in and go to **Account > Orders**.
2. Select the order and click **Return items**.
3. Choose the items and the reason for the return.
4. Print the prepaid return label (see "Return Shipping Labels").

## Return shipping cost

Return shipping is **free** when the item is defective or we shipped the wrong item. For any other reason, a flat **$6.95** return shipping fee is deducted from the refund.

## What happens next

Once the item arrives at our warehouse and passes inspection, the refund is processed as described in the "Refund Policy". If you would rather receive a different item instead of money back, request an exchange instead (see "Exchange Policy").
