# Voltix Cloud Backup: Backup and Restore

## How backups work

The Voltix Cloud Backup client backs up the selected folders **every hour** while the computer is online. Files are encrypted before they leave your device.

## File versions

Each time a file changes, a new version is kept. Previous versions are kept for **30 days**.

## Restoring files

1. Open the Cloud Backup client or the web portal.
2. Choose **Restore** and select the files or folders.
3. Pick the version date and the destination folder.

Large restores (above 200 GB) can be shipped on an encrypted drive for Cloud Backup 5 TB subscribers, at no extra cost.

## Deleted files

Files deleted from your computer stay recoverable in the backup for **30 days**, then are removed permanently.

## Backup stuck or slow

- Check that the computer is not in battery-saver mode, which pauses backups.
- Exclude very large temporary folders (such as video editing caches).
- Check your plan's storage usage in **Account > Subscriptions**.
