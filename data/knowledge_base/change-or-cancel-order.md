# Changing or Cancelling an Order

## Changing an order

You can change the shipping address, shipping option or items of an order while its status is **Received**. Go to **Account > Orders > Edit order**.

Once the order status changes to **Preparing**, it can no longer be edited. This usually happens within **60 minutes** of placing the order.

## Cancelling an order

- **Before it ships:** cancel from **Account > Orders > Cancel order** while the order is Received, or ask support while it is Preparing. No charge is captured; the authorization hold is released by your bank.
- **After it ships:** the order can no longer be cancelled. Refuse the delivery or start a return when it arrives (see "Return Policy").

## Changing the address after shipping

After shipping, the address can only be changed through the carrier's own redirect service, when the carrier offers it. Voltix support cannot change it for you.
