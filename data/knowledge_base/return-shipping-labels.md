# Return Shipping Labels

Every return or exchange started in **Account > Orders** comes with a prepaid return label.

## Getting your label

- The label is shown on screen when you finish the return request and is also sent by email.
- You can download it again at any time from the order page.
- If you do not have a printer, choose **QR code** instead: the carrier prints the label at the drop-off point.

## Validity

Return labels are valid for **14 days** after they are created. If a label expires, start the return again from the order page to generate a new one, as long as you are still within the return window.

## Packing and drop-off

- Use the original box when possible, or any sturdy box with padding.
- Remove or cover old shipping labels on the box.
- Drop the package at any location of the carrier shown on the label and keep the drop-off receipt until the refund or exchange is complete.

One label covers one package. If your return needs more than one box, contact support to request additional labels.
