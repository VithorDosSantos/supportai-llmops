# Troubleshooting Wi-Fi and Network Connectivity

These steps apply to Voltix routers, mesh systems and smart-home hubs.

## Basic checks

1. Restart the device: unplug it for **30 seconds**, then plug it back in.
2. Restart your modem or internet box in the same way.
3. Check the status light. Solid white means connected; blinking amber means no internet connection.
4. Move the device closer to the router to rule out signal problems.

## Slow or unstable Wi-Fi

- Use the **5 GHz** band for devices close to the router and **2.4 GHz** for distant ones.
- In the Voltix app, run **Network > Optimize channel** to move to a less congested channel.
- Make sure the router has the latest firmware (see "Firmware Updates").

## VPN connections

If a VPN client fails to connect only on a Voltix network, enable **VPN passthrough** in **Network > Advanced** and restart the router.

## Still not working

Reset the device to factory settings by holding the reset button for **10 seconds**. This erases its configuration. If the problem persists after a reset, contact Technical Support with the diagnostics file from **Settings > Help > Send diagnostics**.
