# User Seats and Licenses

Voltix Business is billed **per seat**. Each active user occupies one seat.

## Adding users

Administrators add users in **Admin > Users > Invite**. If no seat is free, a new seat is added automatically and the **prorated** price for the rest of the billing period is charged.

## Removing users

- Deactivating a user frees the seat immediately for someone else.
- The total number of seats is only reduced at the **next renewal**. Reduce the seat count in **Admin > Billing > Seats** before the renewal date.

## Reassigning a license

When an employee leaves, deactivate the user and invite the new one: the seat is reused at no extra cost. The former user's files can be transferred to another user within **30 days** of deactivation.

## Automatic provisioning (SCIM)

On Business Plus, SCIM 2.0 creates and deactivates users automatically when they are added or removed in your identity provider. Setup is in **Admin > Security > Provisioning**.
